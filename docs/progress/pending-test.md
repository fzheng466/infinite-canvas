# 待测试

## 电商换装双工作流

### 工作流一「模特动作底图」（换脸）
- 参考图要求 8 张：图片1 模特全身底图、图片2 人物肖像图（正脸）、图片3-8 六个视角的现有图。
- 打开模板后应直接出现六个视角草稿（视角图1~6），每张对应一张视角图，不调用文本模型。
- 每张提示词应强调：姿势/服装/构图/背景与视角原图完全不变，仅脸部换成肖像中的同一人；体型比例与全身底图一致。
- 参考图不足 8 张时，单张和批量生成均应提示缺少参考图。

### 工作流二「商品多视角换装」
- 参考图要求 9 张：图片1-6 为工作流一产出的六张模特图，图片7-9 为商品三角度图。
- 六个草稿分别以对应底图为构图/人物/背景基准，仅替换服装并按角度还原商品细节。
- 参考图不足 9 张时应提示缺少参考图。
